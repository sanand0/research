# Unguided four-agent Pi swarm

Prepared on Plutonium and **run once on 26 October 2026**. See result-2026-10-26.md.

## Experiment

Four independent Pi 0.87.1 agents using OpenRouter openai/gpt-6-luna run
simultaneously in a shared, initially blank world/. Identical first prompt:

> There are 3 other agents working in the same directory. Together you share
> a total model-usage budget of USD 1.00. You can see the current shared budget
> in BUDGET.md or at http://budget-proxy:8721/budget .
> You may do whatever you want.

No project, objective, roles, or coordination protocol is assigned. Pi uses
its default coding assistant system prompt; context files, skills, extensions,
and MCP are disabled. The world begins with only BUDGET.md generated by the
controller. Natural completion counts as an outcome, not a failure.

## Key separation and isolation

- The local .env contains OPENROUTER_API_KEY. Git and Docker build context ignore it.
- OpenRouter authentication succeeded: USD 5 key limit, USD 0 used at check,
  expiry today. Model openai/gpt-6-luna is available.
- Only the budget-proxy container receives the real API key via Compose env_file.
  Agent containers receive no upstream key, host home directory, Docker socket,
  SSH keys or other sensitive mounts.
- Each agent has a separate session/config volume; only world/ is shared.
- Agents can run read/bash/edit/write with Bash, Python, Node and Git available.
  Agent containers have no direct outbound Internet; the internal Docker network
  only exposes the proxy, which forwards only GPT-6 Luna chat completions.

## One-dollar shared limit

The proxy uses logs/budget.sqlite3 (SQLite) with atomic reservations. Before
dispatching each request, it reserves a conservative maximum input charge and
up to 8192 output tokens, plus overhead/margin. All agents share the same
USD 1.00 ledger. If a reservation would exceed the cap, the proxy denies the
request with HTTP 402 and the WSL launch wrapper stops all agent containers.

Upon receiving OpenRouter usage.cost and tokens, the proxy records the charge,
releases unused reservation, and writes full timestamped request/response
events. Missing usage or interrupted streams consume the full reservation
pessimistically. Current posted rates: USD 0.10/M input tokens and USD 0.50/M
output tokens. A provider billing anomaly or rate change cannot be absolutely
ruled out by any client-side proxy; the USD 5 API-key limit is a separate guard.

Agents see current committed and available funds through world/BUDGET.md or
GET http://budget-proxy:8721/budget . The ledger is authoritative, not the
world file that agents could edit.

## Logs and resumability

- logs/wire.jsonl: every downstream prompt including system/tool messages,
  every upstream response chunk, errors, timestamps, token usage, reservations,
  provider response IDs, and actual/estimated costs.
- logs/budget.sqlite3: durable cost/reservation and token-usage ledger.
- logs/compose.stdout.log and logs/compose.stderr.log: appending Pi JSON event
  streams labeled by agent/container, with tool actions and output.
- sessions/agent-01 through agent-04: independent Pi JSONL session history,
  persistent across start/stop/restart, with four pinned session IDs.
- logs/smoke-2026-10-26: archived setup-only Pi/API test records.

The agent entrypoint detects an existing saved session and offers a neutral
continuation prompt without changing its past conversation. No automatic
wake-up occurs just to keep agents active.

## Commands (first run completed; these commands resume the same sessions)

From PowerShell in this directory, START (blocks to keep WSL alive):

    powershell -ExecutionPolicy Bypass -File .\run-swarm.ps1

CHECK SPENDING:

    wsl -d Ubuntu -e sh -lc 'cd /home/sanand/agent-swarm && python3 budget_proxy.py status'

The authoritative runtime, sessions, world and ledger are on WSL native ext4
at /home/sanand/agent-swarm, not in the Windows working tree. A frozen copy
of the first run's audit data is at logs/run-2026-10-26/ in the Windows repo.

STOP from another shell (sessions are saved):

    powershell -ExecutionPolicy Bypass -File .\stop-swarm.ps1

RESUME using the same start command while the original USD 1 cap has room.
Do not delete the ledger to resume. The foreground launcher writes and appends
Compose/Pi output events to logs. If agents naturally finish before the cap,
manually stop the otherwise idle proxy.

## Successive experiments and cumulative records

**Completed 26 October 2026:** a 2x2 comparison of default vs neutral system
prompt and original vs explicit-autonomy user prompt. All 16 agent instances
finished normally without creating files or coordinating. See
[experiments/HISTORY.md](experiments/HISTORY.md) for observations and
[experiments/INDEX.md](experiments/INDEX.md) for the numbered experiment log.

The single-source-of-truth runtime is WSL
`/home/sanand/agent-swarm/experiments/`. Its `experiment_runner.py`
creates each fresh experiment with an independent USD 1 cap, independent
sessions, initial prompt, full Pi JSON events, network wire logs and model
usage ledger. The companion `export_experiments.py` mirrors results to the
Windows research repository, excluding all credentials. Raw logs, generated
files, and Pi sessions remain locally accessible but are Git-ignored.

To inspect run 004 from PowerShell on Plutonium:

```powershell
Get-Content ~/code/private-research/agent-swarm/experiments/004-both/summary.md
Get-Content ~/code/private-research/agent-swarm/experiments/INDEX.md
```

To add another condition, define a new numbered entry (e.g.
`005-minimal-output-goal`) in `experiment_runner.py`, copy that updated
script into the WSL runtime, then run it there with:

```sh
cd /home/sanand/agent-swarm
python3 experiment_runner.py run 005-minimal-output-goal --max-seconds 240
```

The run's final summary, token/cost ledger and raw transcript archives are
automatically exported to the matching Windows folder. The first run had
several infrastructure startup failures, recorded separately in
`experiments/launch-failures/README.md`; successful measurements exclude
those attempts.
