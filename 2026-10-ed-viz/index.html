Can AI actually read an engineering drawing?

Not “can it make something that looks close?” Can it turn a dimensioned drawing into the right editable CAD model — and know when it is wrong?

The only geometry source we gave the agent.

What actually went wrong

Codex told itself a different geometric story.

The hidden reference and Codex both use sensible CAD operations. They just compose the part differently.

Reference
Eye / boss profile
Add main body profile
Add lower / fork profile
Cut mounting holes
Codex
Base + upright
Add separate circular eye
Cut rectangular fork + bore
Cut mounting holes
R3Expected a 3 mm lower-profile radius. Nearest candidate radius was R5.
R6Expected an R6 feature. No final-geometry witness existed.
46.39 mmExpected a fork reference. Nearest candidate measurement was 48 mm.

The failure was not “it cannot read numbers.” It was: the numbers were attached to the wrong geometric relationships.

Why self-correction was not enough

The agent improved against the tests it had.

Its checks were useful. They were just too weak to establish engineering fidelity.

What it checked

  • bounding box
  • one valid closed solid
  • editable feature tree
  • plausible rendered appearance

What it did not check

  • R3 / R6 final profile geometry
  • material distribution and volume
  • surface types and topology
  • whether each dimension belonged to the right relationship

Self-verification is only as strong as the verification kit.

The practical lesson

Put CAD-Bench-like checks inside the agent loop.

Do not wait until the end to discover that the model is beautifully valid and geometrically wrong. Give the agent engineering-grade ways to fail early.

If we want an agent to behave like an engineer, we have to give it engineering-grade ways to know when it is wrong.

Discuss

What does it mean to understand an engineering drawing?

Reading the numbers is not enough. Making a recognizable shape is not enough. So where should we draw the line?

Read the callouts? Recover exact geometry? Recover design intent? Pass assembly tests? Pass physics tests? Know when to ask?
Method and reproducibility

The benchmark task is CAD Bench V3 f32bdb2966, a forked mounting bracket. The reconstruction was blind: the agent workspace did not contain the hidden reference model or grader. The final candidate was frozen before running the official verifier.

The successful run used Codex CLI 0.160.0. A separate local smoke test reported GPT‑6.1 Sol, but the saved reconstruction trajectory does not itself record model identity, so this story refers to the agent simply as Codex.

All reference-versus-candidate images on this page are rendered after rigidly mapping the reference axes into the Codex coordinate frame, then using the same center, scale, orientation and camera. The black-and-white images contain no added labels or callouts.
