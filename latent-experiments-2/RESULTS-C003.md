# C003 — Taylor's-law dominance interpretation under a constraint-preserving null

## Status

**FAILED CONFIRMATION / STOP.**

Discovery found extra temporal organization beyond a strong occurrence+margin null in 2/3 German steppe plots. The frozen independent confirmation found 0/5 Danish heath plots passing. Do not rescue by changing nulls, thresholds, measurements, or confirmation ecosystems on these data.

The narrower reusable result survives: **a raw within-community Taylor slope `b < 2` is not, by itself, evidence that dominant species are biologically stabilized.** In both discovery and confirmation ecosystems, the prespecified constraint-preserving null itself usually had `b < 2`.

## Scientific discrepancy

Gracia et al. (2026, Ecography, DOI `10.1002/ecog.08242`) analyze >9,000 permanent vegetation plots and interpret within-community temporal Taylor-law slopes `b < 2` as a widespread potential stabilizing effect of dominant species: dominant species have lower temporal CV than subordinate species. Their main null comparison is against `b = 2` plus robustness/filtering checks.

A competing statistical explanation is that subquadratic scaling can arise from abundance/census constraints rather than a species-specific stabilizing process. Xiao, Locey & White (2015, DOI `10.1086/682050`) show that the general form of Taylor's law can emerge from feasible-set constraints alone.

C003 therefore asked a sharper question:

> Is the observed `b < 2` / declining-CV-with-mean pattern more dominance-stabilizing than communities that preserve the same species totals, census totals, and occurrence pattern but destroy species-specific temporal magnitudes?

Passing this test would establish temporal organization beyond those constraints. It would **not** uniquely establish causal dominance stabilization.

## Frozen test

Evidence roles and statistics were fixed before discovery mean/variance calculations in `claims/C003.json`.

For each permanent plot/community:

- species are eligible if present in >=15% of census years and temporal variance is nonzero, matching the 2026 analysis;
- community requires >=4 eligible species;
- primary statistic: OLS `b` from `log(temporal variance)` vs `log(temporal mean cover)` across eligible species;
- secondary statistic: `CVratio = arithmetic mean species CV / abundance-weighted mean species CV`;
- null randomizes positive cover magnitudes over the **full** observed species x year matrix while preserving exactly:
  - every species row total,
  - every year column total,
  - the observed positive/zero support (occurrence mask);
- continuous matrices are generated by random positive weights followed by iterative proportional fitting/RAS to the fixed margins;
- primary null weights: iid Exponential(1);
- sensitivity: iid lognormal(0,1);
- 999 null replicates per plot/family;
- plot supports extra dominance-like temporal organization only if `b` is in the lower 2.5% tail **and** CVratio is in the upper 2.5% tail;
- discovery gate: >=2/3 plots pass under both null families.

The support-preserving continuous null avoids arbitrary discretization of percentage cover.

## Confirmation-source execution failures preserved

No source was replaced based on a Taylor/CV outcome.

1. **BioTIME 569** (ponderosa-pine understory) was the initial reserved source. Metadata showed BioTIME exposes count abundance only and no cover `BIOMAS` field. It was rejected **before raw values were fetched** because the frozen confirmation required cover.
2. **BioTIME 240** (Sevilleta pinon-juniper) passed metadata: permanent 1 m2 quadrats, cover, spring/fall sampling. Raw data were opened only to execute the frozen structural gate. Forty quadrat-years contained two distinct September/October fall samples, so there was no unique prespecified fall census. No Taylor/CV statistic was computed. Selecting a month or averaging after this observation was prohibited.
3. **BioTIME 627** was then designated as fresh confirmation with the same statistical test and thresholds.

These failures matter for a live scientific loop: measurement and census semantics can invalidate an otherwise attractive dataset before hypothesis testing.

## Independent verification

A separate DuckDB reconstruction formed the full plot x year x species grids, inserted zeros only for absences within actual censuses, applied the frozen occurrence/variance eligibility filter, and used `regr_slope(ln(var), ln(mean))`. It reproduced all eight discovery/confirmation observed slopes to floating-point precision.

## Interpretation

What failed:

- The discovery claim that extra dominance-like temporal organization beyond abundance/occurrence constraints would generalize to an independent plant-cover ecosystem.

What remains useful:

1. `b < 2` is a mathematical description of declining CV with mean, but it is **not by itself a mechanistic null test**.
2. In all eight plots examined here, the occurrence+margin null itself had typical `b < 2`. Therefore comparing an observed slope only to 2 can attribute to “dominance stabilization” a pattern that is already expected from the conditioned abundance/census geometry.
3. Some communities can nevertheless be substantially more dominance-like than that null (discovery Plots 1 and 3), so the null does not make biology impossible; it separates “subquadratic scaling exists” from “there is extra species-specific temporal organization.”
4. The extra organization did not replicate in the reserved ecosystem, so no general biological claim is justified.

This result is compatible with older feasible-set work showing that Taylor-law form can arise without process-specific mechanisms. It does not demonstrate that the 2026 global result is wrong: the global data, traits, climates, and stability decomposition are much broader, and the present null conditions on quantities that can themselves carry biological information. It demonstrates that **`b < 2` alone is not diagnostic of the proposed mechanism** in these datasets.

## Stop decision

**STOP C003 after failed confirmation.**

Do not now decompose which preserved constraint creates low b, choose another confirmation ecosystem, change the null generator, or relax the confirmation rule on these same data. Those are new hypotheses requiring fresh evidence.
