## Generate front-end

<!--
cd ~/code/research/llm-writing-style
dev.sh -- claude --dangerously-skip-permissions --model fable --effort medium
-->

Create a single page `index.html` to view and pick from different LLM writing styles in `results.json`.

The user's main aim will be to choose a style they'll want to ask a model to write in. They might have a model in mind, or they might want to decide which model to pick.

The user should easily be able to:

- Select a task and see how a given model writes the same text in different styles
- Select multiple tasks and see how a given model writes the same text in different styles
- Select a task and see how a few or all models write the same text in a given style (maybe across multiple styles)
- Select a style and see how different models render it for a given or multiple tasks

It's unlikely they'll want to select a model and see how it renders different styles for one or more tasks, but if they do, it should be possible. (You get the idea, broadly, I guess.)

Keeping this in mind, think about the right interface.
Note that some text is long and wide, some is broken into multiple lines. Future tasks may have longer text.

I expect that we won't have more than 10 models at any time, and no more than 5 tasks, but we may have up to 50 styles in the future.

I plan to re-order styles so that the ones on top are more important. Likewise for models and tasks - so irrespective of the "results" order, preserve the order of models, tasks, and styles from `results.json`.

---

A few issues to fix:

- There are two vertical scrolls: the main page, AND inside `#grid`. Let's just have 1 vertical scroll.
- Use a nice multi-select component for tasks, models, and styles that collapses them into a single field rather than having them sprawl across - I'll add several more of these.
- When changing the layout (rows / columns), the cell loses focus, so I can't press arrow keys repeatedly to change layouts - fix that.
- The colors (both dark and light modes) and font choices look too Claude-like. Instead, copy the design of any popular site that's relevant for such content.

---

- Clicking on the "Copy" button should produce some visual feedback.
- Clicking outside a modal should close the modal.
- The "Copy" button in a result .cell should copy all the tasks, styles, and outputs displayed in the cell, joined as Markdown, separated by headers.
